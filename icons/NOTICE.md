# Core action icon sources

The following 21 toolbar/action SVGs match the regular icons in [Phosphor Icons core 2.1.1](https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e/assets/regular), at fixed commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`. Preserve the complete [Phosphor MIT license](../tools/release/notices/Phosphor-Icons-2.1.1-LICENSE.txt) with these sources and their compiled product distribution.

All SVG element trees, non-root presentation attributes, text, ordered children and path data match that source. Local roots add `width="32" height="32"` and use `fill="#000000"` instead of `currentColor`. Geometry has not been changed. This is a verified matching upstream revision; the original import did not record its download URL/version, so this does not claim to reconstruct that historical download.
